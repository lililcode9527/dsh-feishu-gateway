# 飞书后台配置清单（一次性，约 10 分钟）

> 目标：创建一个飞书"企业自建应用"，让机器人能收到你手机发的消息、并以机器人身份回复。
> 完成后你会得到 **App ID** 和 **App Secret**，填进 `feishu-gateway/.env` 即可。
> 全程在浏览器里操作，不需要写代码。建议用电脑浏览器操作，与手机端同步无延迟。

---

## 第 1 步：创建应用
1. 打开 https://open.feishu.cn ，用你的飞书账号登录。
2. 点右上角 **开发者后台**（第一次会提示创建企业/组织，个人可免费创建，按引导走即可）。
3. 点 **创建企业自建应用**，名称随意（如 `DSH机器人`），创建后进入应用详情页。

## 第 2 步：添加机器人能力
4. 左侧 **应用能力** → **添加应用能力** → 选 **机器人** → 确认。

## 第 3 步：开通权限
5. 左侧 **权限管理** → 搜索并分别 **开通** 以下两项（每个点"开通"）：
   - `im:message`（获取与发送单聊、群组消息）
   - `im:message:send_as_bot`（以应用身份发消息）
6. 开通后权限状态会显示"待发布"，第 5 步发布后生效。

## 第 4 步：事件订阅（关键，决定能否用"长连接"免公网）
7. 左侧 **事件与回调** → **订阅方式** 选择 **「使用长连接接收事件」**（不要选 Webhook 回调，那需要公网地址）。
8. **事件** → **添加事件** → 搜索 `im.message.receive_v1`（接收消息）→ 添加。
9. 事件旁"订阅方式"确认显示为"长连接"。

## 第 5 步：发布版本（权限和事件才生效）
10. 左侧 **版本管理与发布** → **创建版本** → 版本号随意（如 1.0.0）→ 可用范围选全员或你自己 → 创建并 **发布**。
11. 自建应用发布后通常即时生效；如提示审核，可在发布记录里自行通过。

## 第 6 步：拿凭据
12. 左侧 **凭证与基础信息** → 复制 **App ID** 和 **App Secret**。

## 第 7 步：验证可用（可选但推荐）
13. 回到网关目录，把两个值填入 `.env` 后运行：
    ```bash
    npm run check     # 会验证 DSH 可达 + 凭据是否有效
    npm start         # 看到 long-connection started (WS) 即成功
    ```
14. 手机飞书 App → 搜索你的机器人名字（或应用名称）→ 进入会话 → 发消息测试。

---

## 常见问题
- **`npm run check` 报"飞书返回错误 code=10003"**：App Secret 填错或复制多了空格；重新复制粘贴。
- **事件订阅里找不到"长连接"选项**：确认第 4 步在"事件与回调"页面操作，且应用版本已发布。
- **机器人发不出消息**：`im:message` / `im:message:send_as_bot` 权限未生效（先发布版本）或可用范围不含你。
- **手机搜不到机器人**：应用已发布且可用范围包含你；也可在企业通讯录"应用"里找到。
- **App Secret 安全**：泄露=别人可完全控制你电脑上的 DSH。不要提交到任何仓库/聊天；`.env` 已在 `.gitignore` 中。
